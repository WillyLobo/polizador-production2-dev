1. La idea: una plantilla por alcance

El texto de una resolución de certificado es casi siempre el mismo, salvo por los datos que cambian: la obra, la empresa, el monto, el período. En lugar de reescribirlo cada vez, se carga una vez un texto base con huecos, y el sistema completa los huecos con los datos de cada certificado.

Los huecos se escriben entre llaves dobles. Por ejemplo, este texto base: 

Que la Empresa {% templatetag openvariable %} empresa.nombre {% templatetag closevariable %} certificó {% templatetag openvariable %} certificado.monto_pesos|pesos {% templatetag closevariable %};

sale así en el documento:

Que la Empresa Constructora Sur SRL certificó $1.500.000,00;

2. Cómo se elige el texto de cada certificado

Cada texto se carga para un alcance: un Programa, un financiamiento (Nación / Provincia / Terceros) y un tipo de certificado. Cuando se pide la resolución de un certificado, el sistema busca en este orden:

  1. El texto de ese Programa, ese financiamiento y ese tipo exacto.
  2. Si no existe, el de ese Programa y financiamiento con el tipo vacío (el «comodín»: sirve para cualquier tipo).
  3. Si tampoco existe, avisa que falta cargar el texto y ofrece crearlo.
Conviene cargar un comodín por Programa y financiamiento, y agregar textos por tipo sólo donde el articulado realmente cambia — típicamente los Anticipos, que no dicen lo mismo que un avance de obra.

3. Los bloques del cuerpo

El cuerpo se arma con bloques, y el tipo de cada bloque decide su formato en el documento final:

TipoQué hace
VISTOPárrafo que arranca con «VISTO: » en negrita.
Encabezado en negritaTodo el párrafo en negrita: «CONSIDERANDO:», «Por ello;».
ConsiderandoPárrafo justificado con sangría de primera línea.
Fórmula «EL PRESIDENTE … RESUELVE:»Texto fijo centrado. El bloque marca dónde va; no se edita.
ArtículoPárrafo que arranca con «Artículo Nº: » en negrita.
Los artículos se numeran solos según su posición: si agregás uno en el medio, los de abajo se renumeran. Dejá la etiqueta vacía salvo que necesites algo distinto (por ejemplo «Artículo 1º y 2º:» o «De forma:»).

6. Generar la resolución de un certificado

  1. Entrá a la ficha del certificado y tocá Resolución.
  2. Se muestra el texto ya resuelto, con los datos de ese certificado puestos.
  3. Podés retocar la redacción: lo que edites queda guardado sólo para ese certificado, no cambia la plantilla.
  4. Generar documento (.docx) descarga el archivo, armado sobre el membrete institucional vigente.
Si después cambian los datos del certificado (el monto, el expediente, el período), el texto retocado se descarta solo y se vuelve a resolver desde la plantilla: así no queda una resolución diciendo un monto que ya no es.

7. Errores comunes

«Faltan datos: obra.nomber»
El nombre de la variable está mal escrito, o el dato no está cargado. Mientras falte algo no se puede generar el documento: una resolución se firma, y es peor que salga con un hueco a que no salga. Usá la paleta en vez de escribir la variable a mano.
«Error de sintaxis en la línea 1»
Faltó cerrar unas llaves. Revisá que cada {% templatetag openvariable %} tenga su {% templatetag closevariable %}.
«No hay ningún documento base cargado»
Falta subir el membrete institucional. Se sube desde Viáticos → Actualizar Encabezado, y es el mismo que usan las resoluciones de viáticos.
«No hay ningún texto de resolución cargado»
No hay plantilla para el Programa, financiamiento y tipo de ese certificado. La pantalla te dice cuál es el alcance que falta y te lleva a cargarlo.
